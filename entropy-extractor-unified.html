Pipeline di Estrazione Entropica Multi-Finestra — Versione Unificata

Build 4.0.0-beta2 — BETA non ancora pubblicata su GitHub. Motore: Peres + Toeplitz + Clopper-Pearson (MCV/Collision/t-Tuple/LRS) + RCT/APT. Test: 9/15 NIST SP 800-22. Digest: SHA-256 + SHAKE256 opzionale. Changelog completo: CHANGELOG.md.
DOCUMENTAZIONE ESSENZIALE
• Il seed utente è pubblico: non deve essere segreto (proprietà del Leftover Hash Lemma).
• Nessuna creazione di entropia in modalità rigorosa (default): mai bit sintetici silenziosi.
• Gate obbligatori: lunghezza post-Peres ≥ 1024 bit; H_min sorgente ≥ 0.05 bit/bit oppure ≥ 256 bit assoluti; almeno un blocco Toeplitz completo (512 bit in ingresso).
• Non sostituisce l'intera batteria SP 800-90B/800-22 (mancano Markov, compressione/Universal di Maurer, LZ78Y, ecc. — dichiarato come tale).
• Changelog completo delle correzioni matematiche: CHANGELOG.md. Note d'audit dettagliate (versioni precedenti): AUDIT-NOTES.md. Principi di design: SECURITY-NOTES.md.
